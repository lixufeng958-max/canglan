# 3D 模型需求规格书（2026-11-15）

> 核心要求：游戏里的所有人物必须是真正的 3D 模型，放在 3D 场景里跑。
> 不再使用任何平面贴图、PNG 精灵、Canvas 手绘图片做人物。
> 人物要能转身（朝移动方向）、走路时四肢在三维空间里摆动、死亡时整个人在三维空间里倒下。

## 一、模型文件（共 7 个，GLB 格式）

| 文件 | 角色 | 身高（米） | 特点 |
|---|---|---|---|
| `hero.glb` | 主角士兵 | 1.8 | 钢盔、战术背心、双手持步枪 |
| `zombie_ordinary.glb` | 普通丧尸 | 1.8 | 破烂灰衬衫、双臂前伸、头微歪 |
| `zombie_runner.glb` | 疯跑者 | 1.8 | 前倾奔跑姿态、背心、黄色眼睛 |
| `zombie_bloater.glb` | 肥胖爆炸 | 1.8（宽 1.25 倍） | 巨大肚子、污渍衬衫 |
| `zombie_giant.glb` | 巨型 | 2.7（1.5 倍） | 巨大肩膀手臂、灰绿裂纹皮肤 |
| `zombie_spitter.glb` | 喷吐者 | 1.8 | 驼背、喉咙发光绿囊、黑卫衣 |
| `zombie_crawler.glb` | 爬行者 | 贴地爬行（长约 1.6） | 身体水平、四肢着地爬行 |

- 风格：低多边形（low-poly）写实配色，干净色块 + 粗糙材质；细节靠配色和体型区分，不靠贴图。
- 每个模型都是真正的三维几何体（头、躯干、四肢、武器都是独立的立体部件），不是一张平面的图片。
- 文件很小（每个 135–165 KB），共约 1 MB，加载快。

## 二、游戏必须改成 3D 渲染

- 渲染器：Three.js（WebGL），不要再用 Canvas 2D 画人物。
- 相机：俯视 3/4 视角（从斜上方往下看，和现在游戏的视角一致），正交或透视相机均可，推荐透视相机 40° 左右。
- 灯光：半球光 + 一盏方向光（带阴影），地面接收阴影；另加手电光圈（聚光灯，跟随主角）。
- 地面、墙、道具继续用 3D 几何体或现有方式；人物一律用下面的 GLB 模型。
- 人物朝向：模型默认面朝 +Z；移动时把模型根节点绕 Y 轴转到移动方向（`model.rotation.y = Math.atan2(dx, dz)`），不要用图片翻转。

## 三、模型结构（每个 GLB 都一样）

```
Root（根节点：游戏控制位置 + 朝向）
└── Body（身体组：死亡倒下时绕 X 轴旋转）
    └── Hips（胯部：走路起伏）
        ├── Spine → Chest（胸）
        │   ├── Neck → Head（头）
        │   ├── ShoulderL → ElbowL → HandL（左臂）
        │   ├── ShoulderR → ElbowR → HandR（右臂）
        │   └── Rifle（仅主角：步枪，挂在胸前）
        ├── HipL → KneeL → AnkleL（左腿）
        └── HipR → KneeR → AnkleR（右腿）
```

## 四、动画（每个 GLB 自带 4 段，不用再手写骨骼动画）

| 动画名 | 时长 | 动作 |
|---|---|---|
| `idle` | 2.0s（循环） | 待机呼吸：胸微起伏、头微动 |
| `walk` | 按角色走路周期（循环） | 走路：双腿绕髋关节反向摆动、双臂绕肩关节反向摆动（手臂与同侧腿反相）、身体起伏、轻微左右晃；主角手臂小幅摆动（双手持枪） |
| `attack` | 0.5s | 攻击：先收势、再身体前倾扑出、双臂前探 |
| `death` | 0.9s | 死亡：整个人向前扑倒在地（绕身体根部向前倒，不是整张图旋转） |

- 用 `THREE.AnimationMixer` + `clipAction` 播放；走路和待机循环播放，攻击和死亡播一次。
- 死亡播完后保留尸体 15 秒（肥胖爆炸除外：死亡时爆炸、不留尸体）。
- 走路周期（与 `movement-logic.md` 一致）：主角 0.62s、普通 0.85s、疯跑者 0.45s、肥胖 1.0s、巨型 1.2s、喷吐者 0.9s、爬行者 0.7s。

## 五、数值与行为（沿用 movement-logic.md）

- 速度 / 血量 / 伤害 / 攻击间隔 / 刷怪规则，全部沿用 `movement-logic.md`，不改。
- 巨型死亡前血量 <30% 狂暴（速度 ×1.5）；肥胖死亡爆炸（半径 90px、80 伤、对双方生效）；喷吐者在 220px 外停下、0.8s 前摇后吐酸液弹（飞行 260px/s、命中 15 伤 + 地面酸液池 3 秒每秒 5 伤）；爬行者命中判定 −30%。

## 六、验收标准（必须全部满足）

1. 游戏启动后，人物是立体模型：转身时能看到侧面和背面，不是永远一张正脸。
2. 走路时腿和手臂在三维空间里摆动，身体起伏；不是一张图在上下晃。
3. 死亡时整个人向前扑倒在地，能看到倒下的过程。
4. 主角的步枪是立体的、拿在手里的；开枪时枪口有火光、枪身有后坐。
5. 任何情况下都不出现平面贴图人物（`_full.png`、`_head.png`、`_torso.png`、`_leg_*.png`、`_arm_*.png` 全部废弃，不进游戏）。
6. 7 种角色齐全：主角、普通、疯跑者、肥胖、巨型、喷吐者、爬行者，一个不能少。
