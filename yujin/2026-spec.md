# 丧尸射击游戏 · 2026 品质完整需求规格书

目标：成品看起来像 2026 年上线的独立手游，不是 2000 年代 Flash 游戏。参考：《Last Day on Earth》《Alien Shooter 2 重制版》《Soul Knight》的精细度 + 现代手游的打击感。

## 一、视觉基调
- 整体：冷色调夜战，暗绿灰主色 + 暖黄手电光 + 暗红血
- 渲染：全部 SVG 矢量路径绘制，禁止 Canvas 圆形/矩形/胶囊拼接
- 每个精灵 6 层：投影 → 身体 → 服装 → 装备 → 高光 → 描边
- 描边用深色同色系 1px，禁止纯黑描边
- 每块颜色 3 层渐变（亮面/中间/暗面）+ 1 处高光；布料加噪点，金属加高光条

## 二、角色（沿用已定风格，只加细节）
- 画布 128×128，角色占 80%；身体一条连续贝塞尔曲线闭合绘制，四肢锥形、关节曲线过渡
- 主角：头盔盔沿 + 夜视仪支架、战术背心 4 个弹匣袋 + 肩章、护肘护膝、战术手套、军靴鞋带鞋底纹、步枪（枪管/护木纹理/弹匣/枪托/红点瞄具/战术灯）
- 丧尸每种至少 5 处细节：皮肤斑块、咬痕、衣服撕口褶皱、干血渍、裸露骨头；眼睛微弱红光
- 走路 8 帧：膝盖弯曲、脚跟着地脚尖离地、手臂反摆、身体起伏 ±2px；步频与移速同步，脚不打滑
- 攻击 4 帧、受击 2 帧（后仰 + 闪白）、死亡 6 帧（倒地 + 血泊扩散 + 眼睛熄灭）

## 三、光照与阴影（2026 感的关键）
- 手电：径向渐变光锥，边缘羽化 40px；照到墙面时墙面变亮
- 所有角色和道具带实时投影，影子方向跟随光源，长度随距离变化
- 枪口闪光：0.1 秒强光 + 地面光斑 + 照亮周围 1 秒
- 环境：冷色微光 + 暗角 + 薄雾层 + 飘落雨丝和灰尘粒子
- 尸体和血泊在光照下有暗部反光

## 四、场景
- 地面 4 层：水泥底色 → 大块污渍 → 裂纹 → 细节（弹壳/血迹/纸屑/骨头），瓷砖纹理随机不重复
- 墙体 2.5D 挤出：顶面亮、侧面暗、墙角高光、墙根阴影
- 道具每种 3 种变体：木箱、铁桶、路障、尸体、血泊；可破坏的箱子被打碎时掉落零件
- 地图边缘加破损围栏和警示带

## 五、打击感（手感是 2026 和 2000 的分水岭）
- 命中：0.05 秒顿帧 + 目标后仰 + 白色闪光 + 血粒子 12–20 颗（带重力，落地成永久血点）
- 击杀：屏幕震动 0.15 秒 + 红字飘分 + 尸体倒地 6 帧 + 血泊扩散
- 开枪：枪口火光 3 层（白→黄→红）+ 弹壳金色小点弹出落地反光保留 5 秒 + 枪身后坐 2px + 轻微震屏
- 受击：屏幕边缘红晕 0.3 秒 + 血量条抖动 + 角色踉跄
- 爆炸：火光 3 层 + 烟雾 + 冲击波环 + 强震屏 0.3 秒
- 伤害数字飘字，暴击金字放大

## 六、镜头与运动
- 镜头平滑跟随（缓动系数 0.08），不锁死在角色身上
- 移动时镜头微微前倾（朝移动方向偏移 20px）
- 击杀时镜头轻微推近 5%，0.3 秒回弹
- 角色移动带加速度和减速度，起步 0.15 秒加速、停下 0.1 秒滑停，禁止瞬移式启停

## 七、音效（Web Audio 合成，不用外部文件）
- 枪声：低频爆破 + 高频破空，带 0.1 秒回声
- 命中：闷响 + 液体飞溅；击杀：低沉闷哼 + 倒地声
- 丧尸：低吼、脚步拖沓声，距离越近越响
- 环境：雨声底噪 + 远处雷声随机
- UI：点击清脆、拾取叮声、任务完成上扬音
- 所有音效带音量衰减（距离越远越小）

## 八、UI（现代手游 HUD）
- 左上：血量条（渐变红 + 白色受击闪光）+ 护甲条
- 右上：小地图（半透明圆角，带方向和任务点）
- 右下：技能钮（医疗/换弹/手雷/翻滚），带冷却遮罩扫过动画
- 弹药：数字 + 弹匣图标，换弹时转圈动画
- 任务提示：顶部横条，打字机逐字出现
- 受击红晕、击杀红字、拾取提示全部带淡入淡出
- 字体：无衬线粗体，带 1px 深色描边，禁止纯黑底白字大色块

## 九、氛围与后处理
- 暗角 + 轻微胶片颗粒 + 冷色滤镜 + 泛光（bloom）
- 雨效：斜落雨丝 + 地面涟漪 + 偶尔闪电照亮全屏 0.1 秒
- 雾气：地面薄雾缓慢流动

## 十、验收标准
- 静止截图放大 2 倍看不到色块锯齿；角色静止能看清 5 处以上细节
- 开一枪能看到火光、弹壳、后坐、震屏四件事同时发生
- 打中丧尸能看到顿帧、血粒子、后仰、飘字
- 走路时腿的动作清晰，脚不打滑
- 全程 60fps，掉帧时自动降粒子数量

## 执行顺序
① 角色精灵 → ② 光照阴影 → ③ 打击感特效 → ④ 镜头运动 → ⑤ 音效 → ⑥ UI → ⑦ 后处理。每做完一步截图验收，通过再做下一步，不要一次性全改。
