# 运动与行动逻辑需求（给 Claude）

目标：主角和丧尸的移动、攻击、死亡全部有真实的重量感和节奏感，禁止瞬移式启停、禁止原地滑步。

## 角色模型（最重要，先读这一节）
- 每个角色都是一个**装配好的完整模型**，不是一张平面贴图：游戏里每帧都由头、身体、左腿、右腿四个部件按骨架拼装而成，部件之间有真实的关节和相对运动。
- **禁止**把 `*_full.png` 当作游戏内的精灵直接画出来。那张整图只是用来对照比例和外观的参考图，不进游戏。
- 骨架层级：根节点（位置 + 朝向）→ 身体（上下起伏、前后倾斜、左右微晃）→ 头（跟随身体、微晃）→ 左臂 / 右臂（各自绕肩关节旋转）→ 左腿 / 右腿（各自绕髋关节旋转）。
- 走路不是"图片在平移"：双腿绕髋关节反向摆动，双臂绕肩关节反向摆动（手臂与同侧腿反相，跟真人走路一样），身体同步起伏、轻微左右晃，脚落地时有顿点；速度为 0 时回到待机姿势。绝不能出现"原地滑步"（腿不动、身体在平移）。
- 主角的手臂与身体一体（双手持枪），不单独摆动；步枪随瞄准方向旋转。丧尸的手臂是独立部件，绕肩关节摆动。
- 两个例外：疯跑者的右臂在原图画面外、喷吐者的右臂被卫衣遮住，这两只只有左臂是独立部件，右臂留在身体部件里。
- 待机：呼吸起伏（身体 ±2px，周期 2 秒），头微动。
- 攻击：身体前倾扑出 + 头前探，0.2 秒前摇、0.3 秒命中判定，攻击完后硬直。
- 受击：身体后仰 + 闪白 0.1 秒 + 击退。
- 死亡：不是整张图旋转倒下——双腿先屈膝跪下，身体向前扑倒，头垂下，部件按骨架塌下去，再加血泊扩散；尸体保留 15 秒后淡出。
- 主角的手臂画在身体部件里（双手持枪），不单独摆动；丧尸的手臂已拆成独立部件，手臂拆件数据见"手臂拆件"一节。

## 通用
- 60fps，delta time；速度单位 px/s
- 所有移动用速度 + 加速度模型，起步加速、停下减速
- 朝向：自由角度；主角武器指向瞄准方向（鼠标/摇杆），身体朝向移动方向

## 主角
- 移动速度 220 px/s；起步 0.15 秒加速到满速，停下 0.1 秒滑停
- 走路动画：骨骼动画，双腿绕髋关节反向摆动 ±15°，周期 0.62 秒，身体起伏 10px；步频与移速同步，速度为 0 时回到待机姿势
- 待机：轻微呼吸起伏 ±2px，周期 2 秒
- 翻滚：0.35 秒，速度 520 px/s，期间无敌，冷却 2 秒；翻滚时腿部摆动加快一倍
- 换弹 1.2 秒，期间不能开火，弹匣图标转圈
- 开枪后坐：枪身后退 2px + 轻微震屏
- 受击：后仰 + 屏幕边缘红晕 0.3 秒 + 0.05 秒顿帧
- 死亡：按骨架倒地（腿屈膝、身体前扑）+ 血泊扩散

## 丧尸通用 AI
- 索敌：视野 500px；听到枪声后索敌范围 800px，持续 3 秒
- 追踪：朝玩家直线移动；遇墙沿墙滑行，不穿墙
- 攻击：进入 46px 攻击范围 → 攻击动画 4 帧（0.5 秒）→ 命中造成伤害 → 攻击后硬直 0.8 秒
- 受击：后仰 + 闪白 0.1 秒 + 击退 12px
- 死亡：按骨架倒地（腿屈膝、身体前扑、头垂落）+ 血泊扩散 + 眼睛熄灭；尸体保留 15 秒后淡出
- 尸潮：同一格子最多叠 3 只，超出则绕开

## 动画状态机
- 状态：idle → walk（速度 > 10）→ attack（进入攻击范围）→ hurt（受击）→ death（血量 <= 0）
- 切换规则：death 最高优先级，不可打断；hurt 可打断 walk/attack；attack 播放完才能切回 walk
- 攻击前摇：攻击动画前 0.2 秒为前摇（可被打断），后 0.3 秒为命中判定
